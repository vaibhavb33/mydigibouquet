# Asset Management & Botanical Media Pipeline (`asset-management.md`)

**Version:** `1.1 (Peer-Reviewed — Pure Node Sharp + Pre-Encoded Audio + Complete Manifest)`  
**Host Compatibility Note:** Automated image optimization, alpha bitmask compilation, and manifest checks execute via Node + **`sharp` (`libvips`)** in `scripts/build-assets.mjs`, requiring **zero `ImageMagick` (`magick`) or `ffmpeg` CLI installations**.

---

## 1. Format Policy (Transparent PNG · WebP · SVG · Audio)

| Asset Class | Source Master Format | Production Delivery Format | Why This Format |
| :--- | :--- | :--- | :--- |
| **Botanical Stems (`28` SKUs)** | Lossless **Transparent PNG** (`1400px–2048px`, shadow-free) in `assets-master/stems/` | **Alpha WebP (`3 LODs`)** + optional fallback lossless PNG export fallback | `~65–75%` byte savings vs PNG (`<15 KB` thumb, `30–60 KB` studio, `<180 KB` export). |
| **Wraps (`5`) & Ceramic/Terracotta (`2`)** | Paired **Transparent PNG** (`back.png`, `front.png`) | **Alpha WebP** (`studio` `700px`, `export` `1400px`) | Clean woven linen/terracotta occlusion layering. (`bare-stems` has `hasVesselTextures: false`). |
| **`Clear Glass Vase`** | Glass rear rim + specular meniscus **PNGs** | **Alpha WebP** (`studio-{back,front}.webp`, `export-{back,front}.webp`) + compiled mask | Uniform path parity with other vessels while driving offscreen refraction pass. |
| **Bows (`4` Cutouts) & Wax Seals (`6`)** | Studio **PNG** (plus matte woven **`natural-twine`** fiber texture) | **Alpha WebP** | Renders silk/velvet/twine grain and wax bevels smoothly (`bowStyleId === "none"` skipped cleanly). |
| **Tabletop Weaves (`4`), Envelopes (`6×2`), Paper Grains (`2`), Watermark (`1`)** | Crisp source PNGs (`512px` tiles / envelope spreads) | **Alpha/Lossy WebP (`< 10 KB` tiled textures)** | Shared pixel identity across DOM stationery, Konva Layer 0, Browser PNG Export, and Server OG! |
| **Editorial Showcase (`Hero, Templates, Occasions, Flowers, Social OGs`)** | High-res curated compositions (`1200px` / `1200×630`) | **WebP (`< 90 KB`) & OG JPEG** | Dedicated `public/assets/v1/editorial/` avoids stretching `200px` thumbs on desktop hero/cards. |
| **UI Icons, Clip Polygons & Brand Hairlines** | Mathematical vectors & masks | **SVGO SVG / TypeScript coordinate arrays** | Crisp `1.5px` stroke controls and exact shared `inWrapPocketMask` / `ceramicInteriorMask` / `glassInteriorMask` clips! |
| **Ambient Music (`5` Active Tracks)** | **Pre-encoded dual M4A (`128k AAC-LC`) + MP3 (`128k`)** committed in `assets-master/audio/` | Copied & size-verified (`< 600 KB`) directly into `public/assets/v1/audio/` | Eliminates any `ffmpeg` build dependency while guaranteeing synchronous iOS Safari & Android playback (`silent` skipped). |

## 3. Automated Optimization & Bitmask Script (`scripts/build-assets.mjs`)

1. **Alpha Edge Decontamination:** Extracts raw RGBA buffer via `sharp`; clears RGB channels on zero-alpha pixels so pale roses/peonies never show matte fringes over `Evening Slate (#262B27)`.
2. **3-LOD Generation (`sharp`):**
   - `thumb`: `200×200px`, `< 15 KB` WebP (`effort: 6`).
   - `studio`: `700px` max edge, `< 60 KB` WebP (`alphaQuality: 100`).
   - `export`: `1400px` max edge, `< 180 KB` WebP (`alphaQuality: 100`).
   - Generates `< 10 KB` tiled WebPs for tabletop weaves & paper grains, `200px` picker `thumb.webp`s for bows & `bare-stems`, `studio`/`export` WebPs for bows/envelopes/seals/watermarks, and responsive (`480w`/`960w`) `editorial` showcase WebPs.
3. **160px Pre-Computed Alpha Hit-Mask + Shared Vessel Geometry (`src/generated/catalog-manifest.ts`):**
   - Downsamples each stem alpha channel to `<= 160px` max edge, thresholds pixel alpha **`>= 31` (`12%`)**, emits base64 bitset `hitmask.json` (`< 1.8 MB` total client RAM across all 28 stems—eliminating heavy `.cache()` allocations). Client runtime converts `12px` mobile touch hit-slop cleanly to `12 / (activeStageScale * stem.scale)`.
   - Compiles `assets-master/masks/{vesselId}.json` normalized polygons (`collarY`, `waterlineY`, `aboveRimRect`, `inWrapPocketMask`, `ceramicInteriorMask`, `glassInteriorMask`, `supportsBow`, `allowedStemVisibility`) directly into `src/generated/catalog-manifest.ts` so Konva `clipFunc`, Browser PNG Exporter, and Server `@napi-rs/canvas` OG share **exact mathematical clip bounds**.
4. **Audio Pass-Through Verification (`No ffmpeg`):** Copies pre-encoded `.m4a`/`.mp3` files from `assets-master/audio/` to `public/assets/v1/audio/`, asserting every active track exists cleanly in both formats and stays `<= 600 KB`.

## 4. Same-Origin Delivery, Responsive Images & Caching

- **Same-Origin First:** All `/assets/v1/*` assets serve from same-origin paths so `HTMLCanvasElement.toBlob()` never hits Safari CORS tainting bugs.
- **Responsive `<Image>` Contracts:** Below-fold cards use explicit `width`/`height` + tailored `sizes`; above-the-fold Hero & `/flowers/[slug]` spotlights use curated `public/assets/v1/editorial/*` WebPs (`>= 700px`) with `priority fetchPriority="high"` (never upscaling `200px` `thumb.webp` files!).
- **HTTP Caching:** `/assets/v1/*` emits `Cache-Control: public, max-age=31536000, immutable`. User V1.1 attachments route through `/api/media/[id]` with `X-Content-Type-Options: nosniff` and `Cache-Control: private, no-store`.
