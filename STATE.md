## Locked Phase 3A Architectural Decisions
1. **Bouquet Engine:** Imperative `konva` (`~55 KB` gz, avoiding React 19 `react-reconciler` mismatch & Fabric's 9-handle mobile bloat) split into `StaticBackLayer`, `ActiveDragLayer` (+ temporary front-drape slot), `StaticFrontLayer`, and top `SelectionOverlayLayer`, powered by `160px` offscreen alpha bitmasks (`< 1.8 MB` RAM) + shared pure Canvas 2D compositor (`renderBouquetToContext2D`) across Browser `pixelRatio: 1` PNG exports (`1400px` sequential decode), `/b/[slug]` reveals (`700px` studio tier, zero Konva on `/b/[slug]`), and Node `@napi-rs/canvas` OG cards.
2. **Backend, DB & Asset Toolchain:** SQLite/LibSQL via `drizzle-orm` + `@libsql/client` (`file:./data/mydigibouquet.db` locally w/ per-connection `PRAGMA foreign_keys = ON`, Turso in prod), `8` hardened tables separating normalized editable `bouquet_projects`/`bouquet_elements` from immutable `shared_bouquets` snapshots, `sharp` build-time 3-LOD WebP + vector-polygon compiler + pre-encoded `.m4a`/`.mp3` audio pass-through (zero runtime `ffmpeg`/`magick`), HMAC-peppered IP hashing, CSRF `Origin` enforcement, non-poisoning `404` `/api/og/[slug]`, and strict RSC anti-leak redaction.
3. **Guided 5-Step Creation Workflow (Phase 3C):** 40 botanical SKUs (including `monstera-deliciosa` & `autumn-oak-foliage` alongside Eucalyptus, Fern, Ruscus, Olive, Baby's Breath & Fillers), step-scoped library + selected stem tray (multi-copy, inline decrement/replace), Step 3 `computeArrangementSuggestions` + preset/vessel/ribbon/undo-redo, Step 4 Card Studio (`botanical-cream`/`pressed-linen`/`midnight-velvet`/`deckle-cotton`/`blush-parchment`/`minimalist-editorial`, `paperTintId`, `textColorId`, high-contrast legibility fallback, live preview & blank-message validation), Step 5 `FinalSharePreviewStage` + interactive Envelope Reveal preview + Copy Link / WhatsApp / Native Mobile Share + PNG/JPG exports + Start Another Bouquet confirmation guard, and `localStorage` draft persistence across all backward/forward transitions.
